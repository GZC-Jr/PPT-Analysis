# PPT-Analysis: 交互式PPT鼠标行为分析与可视化工具

 <!-- 建议您替换为您应用的最新截图 -->

**PPT-Analysis** 是一个基于 PyQt6 开发的桌面应用程序，旨在为用户提供一个强大、直观的平台，用于分析和可视化与PowerPoint演示文稿相关的鼠标行为数据。通过深度整合数据处理、高级算法和交互式图表，本工具能够将原始的鼠标轨迹数据转化为富有洞察力的分析结果。

---

## ✨ 主要功能

本应用围绕四大核心工作区构建：**演示**、**表格**、**图表**和**分析**，提供从数据回放到深度挖掘的全方位功能。

### 🎨 演示 (Presentation)

动态复现用户在演示过程中的鼠标行为，提供电影般的回放体验。

- **轨迹回放**: 在原始PPT幻灯片背景上，根据CSV数据中的时间戳精确、动态地绘制鼠标移动轨迹。
- **高亮标记点**: 自动识别并以不同颜色（可自定义）高亮显示**移动**、**停留 (HOVER)** 和 **点击 (CLICK)** 事件。
- **动态尾迹效果**: 开启“尾迹”模式，轨迹线将呈现动态渐变消失的效果，清晰地展示最近的鼠标路径。
- **灵活的播放控制**:
  - **倍速播放**: 支持 0.5x 至 20x 的速度调节，可通过滑块或手动输入。
  - **等距播放**: 以 0.1s 至 10s 的固定时间间隔播放每个数据点。
  - **进度控制**: 拖动进度条或输入页码，可即时跳转到演示的任意时间点或幻灯片。
- **高度可定制化**:
  - **轨迹线样式**: 右键点击可调整轨迹线的**颜色**、**粗细**和**线型**（实线、虚线、点线）。
  - **标记点样式**: 右键点击可分别自定义不同类型标记点的**颜色**和**半径**。

### 📈 表格 (Table)

提供一个类似Excel的强大界面，用于查看、编辑和管理原始的CSV数据。

- **直接编辑与批量修改**: 双击单元格即可修改内容。支持多选、整行/整列选择等高级操作。
- **动态排序**: 点击任意列的表头即可实现**升序**或**降序**排列，并带有清晰的视觉指示器。
- **强大的查找与替换**:
  - **高亮查找**: 实时定位匹配的单元格，并以**高亮闪烁动画**进行提示。
  - **高级替换**: 支持替换当前项或**全部替换**。
- **数据管理**:
  - **应用/还原**: 所有修改在“应用”前均可一键“还原”到初始状态。
  - **数据导出**: 可将当前（已编辑和排序）的表格数据导出为新的CSV文件。
- **样式标记**: 选中单元格，可自定义其**字体颜色**，用于标注重点数据。

### 📊 图表 (Chart)

利用 **ECharts** 的强大渲染能力，将枯燥的数据转换为交互式、美观的可视化图表。

- **多图表类型**: 支持一键生成**条形图**、**散点图**和**折线图**。
- **数据源筛选**: 可指定图表的数据来源为**全局数据**或**特定某一页PPT**的数据，实现深度下钻分析。
- **变量选择**: 自由选择任意数据列作为图表的**自变量(X)**和**因变量(Y)**。
- **健壮性保障**: 内置变量组合合理性检查，当选择不兼容的数据（如对文本进行散点分析）时，会弹出友好提示而非程序崩溃。
- **图表导出**: 可将生成的图表导出为高质量的 **PNG** 或 **SVG** 图片。

### 🔬 分析 (Analysis)

应用的核心，提供专家级的聚类和关系分析功能，揭示数据背后更深层次的模式。

#### 模块 (Module) 分析

- **DBSCAN聚类**: 自动将空间上邻近的标记点聚类为“模块”，并在对应的PPT背景上以半透明圆圈可视化。
- **三维阈值过滤**: 用户可自定义**邻近阈值 (eps)**、**聚集阈值 (min_samples)** 和**强度阈值**，只有同时满足所有条件的聚类才会被识别为有效模块。
- **动态视觉映射**:
  - **半径**: “模块”圆的半径真实反映其所包含标记点的**最小包围圆**。
  - **透明度**: 圆的透明度与其**强度 (D)** 负相关，强度越高的模块越不透明。
  - **颜色**: 圆的颜色根据其在页面上的**位置**在用户设定的**颜色梯度**（起始色-终止色）中进行映射，位置相近的模块颜色也相近。
- **关联度分析**:
  - 自动计算并绘制模块间的**关联连线**。
  - 连线的**粗细**精确映射两个模块间的**关联强度 (L)**，关联越强，连线越粗。
- **交互式样式设置**: 提供专门的“样式设置”对话框，允许用户实时调整模块的**颜色渐变范围**和**连线颜色**。
- **详细数据导出**: 可将所有页面的所有模块的详细信息（页码、半径、强度、包含的每一个标记点的详细数据）导出为一份结构化的CSV文件，文件名自动包含阈值信息，便于追溯。

#### 页际 (Inter-page) 分析

- **日历关系热力图**: 将所有PPT页面以网格形式排列，形成一个直观的“日历视图”。
- **强度热力图**: 每个PPT瓦片的**背景色**精确映射该页面的**总强度 (P)**，强度越高颜色越深，帮助用户快速识别高交互页面。
- **自定义颜色映射**: 用户可通过“样式设置”对话框自由设定热力图的**颜色梯度**（起始色-终止色）。
- **异常跳转可视化**:
  - **歧线**: 自动识别并用带箭头的红线标出所有非顺序的页面跳转（如跳页、回退）。
  - **关联**: 可切换显示跳转页面间的关联强度。

## 🚀 快速开始

### 依赖环境

- Python 3.8+
- PyQt6

### 安装

1.  克隆本仓库到本地:
    ```bash
    git clone https://github.com/your-username/PPT-Analysis.git
    cd PPT-Analysis
    ```

2.  安装所有必要的Python包:
    ```bash
    pip install -r requirements.txt
    ```

### 运行

在项目根目录下，执行以下命令即可启动应用程序：

```bash
python main.py
```

###  使用流程
启动程序后，首先点击“上传PPT”按钮选择一个 .pptx 文件。
接着点击“上传CSV”按钮选择一个对应的鼠标行为数据文件。
数据加载成功后，即可在“演示”、“表格”、“图表”和“分析”四个工作区之间自由切换，探索您的数据。

## 🛠️ 技术栈
桌面GUI框架: PyQt6
数据处理与分析: Pandas, NumPy, Scikit-learn
交互式图表: PyQtWebEngine + Apache ECharts
PPT文件处理: python-pptx
PPT幻灯片渲染: Windows COM Automation (via pywin32)
